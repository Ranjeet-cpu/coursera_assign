
# Simple Interest Calculator

## Description
The Simple Interest Calculator calculates interest on a principal amount based on the rate of interest and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Example

Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 × 5 × 2) / 100
Simple Interest = 100

Total Amount = Principal + Simple Interest
Total Amount = 1100

## Features
- Calculates simple interest.
- Accepts principal, rate, and time.
- Displays the interest and total amount.
- Easy to understand.

## Technologies Used
- Markdown for documentation.
- Can be implemented using Python or JavaScript.
